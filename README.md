# Стикеры

Веб-приложение с доской цветных стикеров. React + TypeScript + Vite, данные, авторизация и фото — в Supabase.

## Возможности

- Регистрация и вход по email и паролю, уникальный ник
- Личная доска (видит только автор) и общая (видят все вошедшие)
- Стикеры: заголовок, текст, 10 цветов, 5 шрифтов, фото (перемещение и изменение размера)
- Перетаскивание стикеров, автосохранение
- Админ (первый зарегистрированный) может удалять любые стикеры
- Фото как отдельные объекты личной доски (`type = 'photo'` в `notes`): «+ Фото», перетаскивание файла и Ctrl+V, подпись, размер, просмотр на весь экран с зумом
- Друзья: публичный ID `XXXX-XXXX`, заявки, список друзей, блокировка (кнопка с людьми в панели; ID — в меню профиля)
- Общие доски с друзьями: вкладки «Личная | Доски», чипы досок, до 7 друзей, Realtime (миграция `20261107000000_shared_boards.sql`)
- Стикер на весь экран: кнопка «развернуть» в углу карточки, чек-лист (☐/☑ в тексте), отмена/повтор, свайп вниз закрывает
- Права стикеров на общих досках (`notes.edit_mode`): «Только я» / «Я и участники», проверка в RLS (миграция `20261108000000_note_edit_mode.sql`)
- Персональный фон доски (`profiles.settings`, бакет `backgrounds`): цвета, градиенты, узоры, своё фото, затемнение и размытие (миграция `20261109000000_profile_background.sql`)
- Светлая и тёмная тема, адаптивная вёрстка

## Запуск

```bash
cp .env.example .env   # впишите VITE_SUPABASE_URL и VITE_SUPABASE_ANON_KEY
npm install
npm run dev
```

Сборка: `npm run build` → папка `dist/` (для SPA нужен fallback на `index.html`).

## Структура

- `src/App.tsx` — авторизация, доска, редактор заметки
- `src/components/PhotoLayer.tsx` — фото внутри заметки
- `src/lib/supabase.ts` — клиент, типы, цвета, шрифты
- `src/lib/photos.ts` — сжатие и загрузка фото
- `supabase/migrations/` — схема БД (применять по порядку)
