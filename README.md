# Стикеры

Веб-приложение с доской цветных стикеров. React + TypeScript + Vite, данные, авторизация и фото — в Supabase.

## Возможности

- Регистрация и вход по email и паролю, уникальный ник
- Личная доска (видит только автор) и доски с друзьями. Общая доска отключена (миграция `20261113000000_disable_public_board.sql`), старые данные не удаляются
- Стикеры: заголовок, текст, 10 цветов, 5 шрифтов, фото (перемещение и изменение размера)
- Перетаскивание стикеров, автосохранение
- Админ (первый зарегистрированный) может удалять любые стикеры
- Фото как отдельные объекты личной доски (`type = 'photo'` в `notes`): «+ Фото», перетаскивание файла и Ctrl+V, подпись, размер, просмотр на весь экран с зумом
- Друзья: публичный ID `XXXX-XXXX`, заявки, список друзей, блокировка (кнопка с людьми в панели; ID — в меню профиля)
- Общие доски с друзьями: вкладки «Личная | Доски», чипы досок, до 7 друзей, Realtime (миграция `20261107000000_shared_boards.sql`)
- Стикер на весь экран: кнопка «развернуть» в углу карточки, чек-лист (☐/☑ в тексте), отмена/повтор, свайп вниз закрывает
- Права стикеров на общих досках (`notes.edit_mode`): «Только я» / «Я и участники», проверка в RLS (миграция `20261108000000_note_edit_mode.sql`)
- Персональный фон доски (`profiles.settings`, бакет `backgrounds`): цвета, градиенты, узоры, своё фото, затемнение и размытие (миграция `20261109000000_profile_background.sql`)
- Рисование на личной доске (таблица `drawings`, штрихи векторно): ручка, маркер, ластик, 8 цветов, 3 толщины, отмена/повтор (миграция `20261110000000_drawings.sql`)
- Режим «детектив»: красные нити между стикерами и фото (таблица `connections`, личная и общие доски): булавки, провисающая кривая Безье, цвет, пунктир, подпись (миграция `20261111000000_connections.sql`)
- Страницы на досках (до 10 на личной и на каждой доске с друзьями): поле `page` в `notes`, `drawings`, `connections`, таблица `board_pages` с названиями; переключатель внизу, свайп на телефоне, перенос объектов (миграция `20261114000000_board_pages.sql`)
- Стиль оформления: «Современный» (по умолчанию) и «Оригинал» — кнопка с палитрой в верхней панели; выбор хранится в localStorage и `profiles.settings.style`, переключается атрибутом `data-style` на `<html>`, тема (`data-theme`) работает в обоих стилях
- Третий стиль «Скевоморфизм» (iOS 6, `data-style="skeuo"`): пробка в деревянной рамке, бумага с загнутым уголком и глянцевой кнопкой, кожаная панель со швом, красная шерсть вместо нити; только CSS (текстуры — встроенный SVG), рукописный шрифт Marck Script подгружается с Google Fonts и необязателен
- Offline-first: все данные читаются и пишутся сначала в локальную базу (IndexedDB, `src/lib/localdb.ts`), поэтому интерфейс мгновенный и личная доска работает без сети. Каждое изменение попадает в очередь (`outbox`) и уходит в Supabase при появлении сети (событие `online`, раз в минуту, при открытии и возврате на вкладку), при сбоях — повтор с растущей паузой (`src/lib/sync.ts`). Удаление «мягкое» (`deleted_at`, миграция `20261115000000_offline_sync.sql`). Конфликты: побеждает версия с более поздним `updated_at`; Realtime пишет входящие изменения в локальную базу. В панели индикатор: «Синхронизировано» / «Ожидает отправки (N)» / «Нет сети». Фото без сети сжимаются и хранятся на устройстве, в Storage загружаются позже. Без сети доски с друзьями открываются только для чтения (плашка «Нет сети»), создавать и менять доски можно только онлайн
- Устанавливаемое приложение (PWA): манифест `public/manifest.webmanifest`, иконки 192/512 (в том числе maskable), service worker с кэшем оболочки (создаётся при сборке плагином в `vite.config.ts`, шаблон `scripts/sw.template.js`), кнопка «Установить приложение» в профиле. Вход сохраняется на устройстве, приложение открывается без сети
- Вкладка «Доски»: если доска не выбрана, предлагает создать новую «Для себя» или «С друзьями»
- Светлая и тёмная тема, адаптивная вёрстка

## Запуск

```bash
cp .env.example .env   # впишите VITE_SUPABASE_URL и VITE_SUPABASE_ANON_KEY
npm install
npm run dev
```

Сборка: `npm run build` → папка `dist/` (рядом с `index.html` создаётся `sw.js`; для SPA нужен fallback на `index.html`). Service worker работает только по HTTPS (GitHub Pages подходит).

## Структура

- `src/App.tsx` — авторизация, доска, редактор заметки
- `src/components/PhotoLayer.tsx` — фото внутри заметки
- `src/lib/supabase.ts` — клиент, типы, цвета, шрифты
- `src/lib/photos.ts` — сжатие фото и постановка загрузки в очередь
- `src/lib/localdb.ts` — локальная база (IndexedDB) и очередь отправки
- `src/lib/data.ts` — локальные операции (создать, изменить, удалить + постановка в очередь)
- `src/lib/sync.ts` — синхронизация с Supabase: очередь, опрос, Realtime, конфликты
- `src/lib/pwa.ts` — регистрация service worker, кнопка установки
- `supabase/migrations/` — схема БД (применять по порядку)

## Блокировка стикера кодом

- В редакторе стикера: «Заблокировать» (код 4–6 цифр, с повтором), «Сменить код», «Снять блокировку» (везде нужен текущий код).
- Закрытый стикер на доске показывает замок: заголовок скрыт, текст размыт, фото не показывается. На общих досках участники видят только замок, открыть может только автор.
- Содержимое (текст, фото) хранится в закрытой таблице `note_locks` (RLS без политик) и отдаётся только функцией `unlock_note` после проверки кода на сервере. Хэш кода (bcrypt с солью) лежит там же; сам код нигде не хранится. В `notes` остаются пустые поля и флаг `locked`.
- 5 неверных попыток подряд — пауза 30 с (на сервере; каждая следующая серия вдвое длиннее, максимум 15 минут).
- Открытый стикер живёт только в памяти: при закрытии редактора он снова закрывается; в IndexedDB, очередь отправки и JSON-копию содержимое не попадает.
- Блокировка, смена кода, снятие и открытие работают только с сетью. **Забытый код восстановить нельзя.**
- Миграция: `supabase/migrations/20261116000000_note_locks.sql` (применять после 13, 14, 15).

## Экспорт доски

Меню страниц (кнопка с названием страницы внизу) → «Экспорт доски…»:
- **Картинка (PNG)** — текущая страница; **PDF** — все страницы, по странице на лист; **Данные (JSON)** — резервная копия.
- Картинка рисуется на canvas из данных: фон, стикеры, фото, нити, рисунок — в выбранном стиле. Заблокированные стикеры выходят закрытыми.
- Прогресс, затем скачивание; на телефоне — кнопка «Поделиться» (системное меню). На общих досках доступно любому участнику.
- Раскладка в файле — как на компьютере (по координатам стикеров), даже если экспорт идёт с телефона.

## Напоминания

- В редакторе стикера кнопка «Напомнить»: быстрые варианты (через час, сегодня в 19:00, завтра в 9:00, через неделю) или своя дата и время. На карточке появляется колокольчик.
- Напоминание личное: хранится в настройках профиля (`profiles.settings.reminders`), синхронизируется между устройствами, работает офлайн, на общей доске его видит только тот, кто поставил. Новой миграции не нужно. Не больше 40 напоминаний.
- Срабатывает, пока приложение открыто (можно свёрнутым): уведомление в приложении плюс системное, если разрешено. Если приложение было закрыто, пропущенное напоминание покажется при следующем открытии. Push при закрытом приложении потребовал бы серверной части и не сделан.
